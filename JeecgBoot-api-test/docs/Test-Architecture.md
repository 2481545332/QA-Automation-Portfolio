# JeecgBoot 自动化测试架构与脑图设计

本图基于“五大测试思考维度”绘制，展示了登录、部门角色、知识库文档三大模块的测试点拆解与实施策略。

```mermaid
mindmap
  root((JeecgBoot<br/>接口自动化测试架构))
    登录模块
      获取验证码
        正向: 正确Key获取
        异常: 空Key/超长Key
      登录操作
        正向: 账号密码正确
        异常: 密码错/账号空/验证码错
        边界: 超长账号密码
        权限: Token未清除/过期
        安全: 并发防重/SQL注入
    部门角色模块
      新增角色
        正向: 全必填项
        异常: 缺必填/部门ID不存在/重复名
        边界: 超长字符串
        权限: 无Token/越权给外部门建角色
        数据同步: Redis与MySQL一致性
      编辑角色
        正向: 局部POST/全量PUT
        异常: 必填空/部门ID不存在
        权限: 越权修改外部门角色
        安全: 并发修改/SQL注入
      删除角色
        正向: 单条删除/批量删除
        异常: 假ID/部分假ID
        权限: 越权删外部门角色
        安全: 物理删除 vs 逻辑删除
      查询角色
        正向: 列表分页/ID详情
        异常: ID不存在返回空
        边界: 超大分页参数
        权限: 越权跨部门查询
    知识库文档模块
      新增文档
        正向: 全必填项新增
        异常: 缺必填/文件夹ID不存在/同名
        权限: 越权伪造创建人
        安全: 并发新增同名文档
      编辑文档
        正向: 正常改名/更新
        异常: 必填空/唯一性冲突
        权限: 越权修改他人文档
        安全: 并发编辑冲突
      删除文档
        正向: 正常单/批删
        异常: 假ID删除
        权限: 越权删除他人文档
        安全: 物理删除验证
      查询文档
        正向: 列表/详情查询
        异常: 不存在ID
        权限: 越权查他人文档
