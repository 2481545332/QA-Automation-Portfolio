# SauceDemo 电商系统 UI 自动化测试计划

## 1. 测试背景与目标
SauceDemo (Swag Labs) 是一个典型的前后端分离电商演示系统，包含登录、商品浏览、购物车、订单结算等核心业务。本项目旨在基于 Pytest + Selenium 搭建 UI 自动化回归测试框架，保障系统核心主流程的稳定性，减少每次迭代的人工回归成本。

## 2. 测试范围
*   **包含**：登录模块（异常校验）、商品列表模块（排序、加购）、购物车模块（增删改、页面跳转）、结算模块（必填校验、下单流程）。
*   **不包含**：前端样式像素级比对、非主流浏览器兼容性测试（仅在 Chrome 执行）、性能与安全渗透测试。

## 3. 自动化策略
*   **设计模式**：采用 PO (Page Object) 模式，实现页面元素与测试逻辑的解耦。
*   **数据驱动**：对于登录异常和结算表单校验等场景，采用 Excel 数据驱动（`@pytest.mark.parametrize`）。
*   **执行策略**：采用 Session 级登录态复用，全局只登录一次，大幅提升执行效率。

## 4. 准入与准出标准
*   **准入标准**：主流程测试通过，前端页面结构趋于稳定。
*   **准出标准**：
    1. 自动化脚本连续运行 3 次，通过率 100%。
    2. 核心 P0 级别主链路（登录->加购->结算）覆盖率 100%。
    3. 产出完整的 Allure 测试报告，且无遗留致命 Bug。

## 5. 风险与应对
*   **风险**：网络波动导致前端加载缓慢。
*   **应对**：在 `BasePage` 中封装全局显式等待（WebDriverWait），彻底摒弃强制等待（`time.sleep`）。
